# Project instructions

- Product: `CHAEVI — AI Work Router` / `채비 — AI 작업 추천기`.
- Keep the public repository understandable without private operational context.
- Keep recommendation logic focused and regression-tested; avoid unrelated refactors.
- Validate relevant changes with `npm test`, `npm run lint`, and `npm run build`.
- Never commit credentials, raw private feedback exports, customer/user data, local absolute paths, or private deployment identifiers.
- AI-assisted contributions are allowed, but contributors remain responsible for correctness, provenance, privacy, and license compatibility.
- Keep `Made by ALDOL` understated and subordinate to the CHAEVI product identity.
